# Stand-der-Technik-Tools

Werkzeuge zur Nutzung der Inhalte der [Stand-der-Technik-Bibliothek](https://github.com/BSI-Bund/Stand-der-Technik-Bibliothek).

## Überblick

Dieses Repository enthält ergänzende Werkzeuge für die Stand-der-Technik-Bibliothek.

Aktuell umfasst das Repository einen Viewer zur Anzeige und Navigation der Bibliotheksinhalte. Weitere Werkzeuge können zukünftig ergänzt werden.

## Bezug zur Stand-der-Technik-Bibliothek

Die Inhalte werden im Repository **Stand-der-Technik-Bibliothek** gepflegt:

https://github.com/BSI-Bund/Stand-der-Technik-Bibliothek

Die in diesem Repository bereitgestellten Werkzeuge dienen der Nutzung und Verarbeitung dieser Inhalte.
