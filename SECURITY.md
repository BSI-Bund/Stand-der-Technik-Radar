# Sicherheitsmeldungen

Bitte keine vertraulichen Quelldateien, Zugangsdaten oder personenbezogenen Daten in öffentliche Issues einfügen. Sicherheitsrelevante Probleme über die privaten Meldewege des öffentlichen Repositorys bzw. die veröffentlichten Kontaktwege des Herausgebers melden.

Die Anwendung verarbeitet versionierte Daten ohne Backend. Änderungen an Abhängigkeiten, Quell-URLs und Veröffentlichungsgrenzen werden im Pull Request geprüft. Der Workflow besitzt standardmäßig nur Leserechte; Pages-Schreibrechte sind auf den Deployment-Job beschränkt.
